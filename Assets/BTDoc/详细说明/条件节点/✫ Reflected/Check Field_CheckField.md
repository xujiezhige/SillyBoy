# Check Field

- 类名：`CheckField`
- 节点类型：条件节点
- 分类：✫ Reflected
- 基类：`ConditionTask`
- 源文件：`Assets/ParadoxNotion/NodeCanvas/Tasks/Conditions/ScriptControl/CheckField.cs`

## 作用

Check a field on a script and return if it's equal or not to a value

## 参数

无公开配置参数。

## 使用备注

条件节点用于判断条件，通常由 Condition Node 或装饰器引用，结果为 true/false。
