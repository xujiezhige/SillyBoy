# CheckCSharpEvent

- 类名：`CheckCSharpEvent`
- 节点类型：条件节点
- 分类：✫ Reflected/Events
- 基类：`ConditionTask`
- 源文件：`Assets/ParadoxNotion/NodeCanvas/Tasks/Conditions/ScriptControl/CheckCSharpEvent.cs`

## 作用

Will subscribe to a public event of Action type and return true when the event is raised.\n(eg public event System.Action [name])

## 参数

无公开配置参数。

## 使用备注

条件节点用于判断条件，通常由 Condition Node 或装饰器引用，结果为 true/false。
