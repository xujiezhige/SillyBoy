# Optional

- 类名：`Optional`
- 节点类型：装饰节点
- 分类：Decorators
- 基类：`BTDecorator`
- 源文件：`Assets/ParadoxNotion/NodeCanvas/Modules/BehaviourTrees/Nodes/Decorators/Optional.cs`

## 作用

Executes the decorated child as normal and returns an Optional status, thus making it optional to the parent node in regards to what status is returned.\nThis has the same effect as disabling the node, but instead it executes normaly.

## 参数

无公开配置参数。

## 使用备注

装饰节点通常包裹一个子节点，用于修改执行条件、结果或生命周期。
