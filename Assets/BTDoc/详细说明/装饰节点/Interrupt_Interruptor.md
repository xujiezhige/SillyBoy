# Interrupt

- 类名：`Interruptor`
- 节点类型：装饰节点
- 分类：Decorators
- 基类：`BTDecorator`
- 源文件：`Assets/ParadoxNotion/NodeCanvas/Modules/BehaviourTrees/Nodes/Decorators/Interruptor.cs`

## 作用

Executes and returns the child status. If the condition is or becomes true, the child is interrupted and returns Failure.

## 参数

无公开配置参数。

## 使用备注

装饰节点通常包裹一个子节点，用于修改执行条件、结果或生命周期。
