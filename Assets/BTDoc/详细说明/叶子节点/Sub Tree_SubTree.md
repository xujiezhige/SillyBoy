# Sub Tree

- 类名：`SubTree`
- 节点类型：叶子节点
- 分类：Leafs
- 基类：`BTNodeNested<BehaviourTree>`
- 源文件：`Assets/ParadoxNotion/NodeCanvas/Modules/BehaviourTrees/Nodes/Leafs/SubTree.cs`

## 作用

Executes a sub Behaviour Tree. The status of the root node in the SubTree will be returned.

## 参数

无公开配置参数。

## 使用备注

该节点属于行为树基础节点，用于连接任务或子图。
