# Sub Dialogue

- 类名：`NestedDT`
- 节点类型：叶子节点
- 分类：Leafs
- 基类：`BTNodeNested<DialogueTree>`
- 源文件：`Assets/ParadoxNotion/NodeCanvas/Modules/BehaviourTrees/Nodes/Leafs/NestedDT.cs`

## 作用

Executes a sub Dialogue Tree. Returns Running while the sub Dialogue Tree is active. You can Finish the Dialogue Tree with the 'Finish' node and return Success or Failure.

## 参数

无公开配置参数。

## 使用备注

该节点属于行为树基础节点，用于连接任务或子图。
