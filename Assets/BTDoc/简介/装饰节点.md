# 装饰节点

节点数量：14

| 节点 | 类名 | 分类 | 简介 | 参数数 |
|---|---|---|---|---:|
| Conditional | `ConditionalEvaluator` | Decorators | Executes and returns the child status only if the condition is true. Returns Failure if the condition is false. | 2 |
| Filter | `Filter` | Decorators | Filters the access of its child either a specific number of times, or every specific amount of time. | 5 |
| Guard | `Guard` | Decorators | Protects the decorated child from running if another Guard with the same token is already guarding (Running) that token.\nGuarding is global for all of the agent Behaviour Trees. | 2 |
| Interrupt | `Interruptor` | Decorators | Executes and returns the child status. If the condition is or becomes true, the child is interrupted and returns Failure. | 0 |
| Invert | `Inverter` | Decorators | Inverts Success to Failure and Failure to Success. | 0 |
| Iterate | `Iterator` | Decorators | Iterates a list and executes its child once for each element in that list. Keeps iterating until the Termination Policy is met or until the whole list is iterated, in which case the last iteration child status is returned. | 6 |
| Merge | `Merge` | Decorators | Merge can accept multiple input connections and thus possible to re-use leaf nodes from multiple parents. Please note that this is experimental and can result in unexpected behaviour. | 0 |
| Monitor | `Monitor` | Decorators | Monitors the decorated child for a returned Status and executes an Action when that is the case.\nThe final Status returned to the parent can either be the original decorated child Status, or the new decorator Action Status. | 2 |
| Optional | `Optional` | Decorators | Executes the decorated child as normal and returns an Optional status, thus making it optional to the parent node in regards to what status is returned.\nThis has the same effect as disabling the node, but instead it executes normaly. | 0 |
| Override Agent | `Setter` | Decorators | Set another Agent for the rest of the Tree dynamicaly from this point and on. All nodes under this will be executed with the new agent. You can also use this decorator to revert back to the original graph agent. | 2 |
| Remap | `Remapper` | Decorators | Remaps the child status to another status. Used to either invert the child's return status or to always return a specific status. | 2 |
| Repeat | `Repeater` | Decorators | Repeats the child either x times or until it returns the specified status, or forever. | 3 |
| Timeout | `Timeout` | Decorators | Interupts decorated child node and returns Failure if the child node is still Running after the timeout period. | 1 |
| WaitUntil | `WaitUntil` | Decorators | Returns Running until the assigned condition becomes true, after which the decorated child is executed. | 0 |
