# 叶子节点

节点数量：5

| 节点 | 类名 | 分类 | 简介 | 参数数 |
|---|---|---|---|---:|
| Action | `ActionNode` | Leafs | Executes an action and returns Success or Failure when the action is finished.\nReturns Running until the action is finished. | 0 |
| Condition | `ConditionNode` | Leafs | Checks a condition and returns Success or Failure. | 0 |
| Sub Dialogue | `NestedDT` | Leafs | Executes a sub Dialogue Tree. Returns Running while the sub Dialogue Tree is active. You can Finish the Dialogue Tree with the 'Finish' node and return Success or Failure. | 0 |
| Sub FSM | `NestedFSM` | Leafs | Executes a sub FSM. Returns Running while the sub FSM is active. If a Success or Failure State is selected, then it will return Success or Failure as soon as the Nested FSM enters that state at which point the sub FSM will also be stoped. If the sub FSM ends otherwise, this node will return Success. | 0 |
| Sub Tree | `SubTree` | Leafs | Executes a sub Behaviour Tree. The status of the root node in the SubTree will be returned. | 0 |
